# VKU Room Booking (Study Room Booking App)

React Native + Expo (TypeScript strict), React Navigation 7 (Stack + Tabs), Zustand (client state, persisted via AsyncStorage), TanStack Query (server state), Reanimated 4 + Gesture Handler.

## Run
```
npm install
npx expo start        # scan the QR with Expo Go
npx expo start --web  # browser preview
npm run typecheck
```
Demo login: `demo@vku.udn.vn` / `123456`, or "Continue as guest".
